# Трекер времени

Простое офлайн веб-приложение для учёта времени по часам, с представлениями «День» и «Месяц».

## Файлы

- `index.html`, `base.css`, `style.css`, `app.js` — исходники приложения.

## Данные

Приложение хранит данные локально в браузере через IndexedDB. База привязана к источнику (origin) страницы — например, разные браузеры или разные способы открытия страницы (локальный сервер, `file://`) могут видеть разные, независимые базы данных.

## Экспорт / импорт

Кнопки внизу экрана «Месяц» позволяют выгрузить все данные в JSON-файл и восстановить их обратно — используйте для переноса данных между устройствами/браузерами или для резервных копий.
