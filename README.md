# Трекер времени

Простое офлайн веб-приложение для учёта времени по часам, с представлениями «День» и «Месяц».

## Файлы

- `index.html`, `base.css`, `style.css`, `app.js` — исходники для разработки (запуск через локальный сервер, например `npx serve .`).
- `mobile.html` — самодостаточная сборка (CSS и JS встроены прямо в файл). Используйте именно этот файл при открытии напрямую на телефоне через файловый менеджер (протокол `file://`) — раздельные `<link>`/`<script>` не всегда подключаются при таком способе открытия на Android.

## Данные

Приложение хранит данные локально в браузере через IndexedDB. База привязана к источнику (origin) страницы:
- Разные браузеры = разные, независимые базы данных.
- `index.html`, открытый как `file://`, и `mobile.html`, открытый как `file://`, могут делить одну и ту же базу (это особенность браузера, а не собственно приложения).
- Локальный сервер (`http://localhost:...`) — тоже отдельный, независимый origin.

## Экспорт / импорт

Кнопки внизу экрана «Месяц» позволяют выгрузить все данные в JSON-файл и восстановить их обратно — используйте для переноса данных между устройствами/браузерами или для резервных копий.
